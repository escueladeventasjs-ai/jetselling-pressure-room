---

## Cómo publicar en GitHub Pages

1. Subir:
- index.html
- style.css
- app.js
- README.md

2. Activar GitHub Pages:

Settings → Pages

Configurar:

- Source → Deploy from branch
- Branch → main
- Folder → /root
